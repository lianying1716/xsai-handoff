# 星算会话交接

把一个长会话压缩成结构化交接文档，存到本机固定位置；新会话说一句「继续上次」，就能自动认领最近一份接着干。适合上下文快满、想重开一个干净会话、或换机器前留个存档。

只做会话交接，不替代通用总结，也不负责多 Agent 之间的任务派发。

## 上下文快满时会先问你

本插件带一个 `PreCompact` 钩子：Codex **即将自动压缩历史**之前，它会先停下来并提示你选一个。

- 这是**插件级**能力，随插件一起装好，不需要额外配置。
- 只拦**自动**压缩。你自己输入的 `/compact` 不受影响。
- 一次会话里只问一次：你被问过之后继续发消息，就会正常压缩，不会把你卡死。

钩子由 Codex 逐条要求信任，首次使用需在 `/hooks` 里 review 并信任；未信任时钩子不会运行（技能本身照常可用）。

## 何时使用

- 用户说「交接一下」「handoff」「压缩上下文」「换个会话继续」「存个交接」→ 走 **SAVE**。
- 用户说「继续上次」「接续」「resume」「load handoff」→ 走 **RESUME**。
- 不做：普通对话总结、记忆检索、已经完成的小任务的收尾。

需要 Node.js 18 或更新版本。`<技能目录>` 指本文件所在目录，不是当前项目目录。

## 存放位置

交接文档统一存到本机固定目录，按系统自动解析：

- Windows：`%USERPROFILE%\.xsai\handoffs`
- macOS / Linux：`$HOME/.xsai/handoffs`

可用 `XSAI_HANDOFF_DIR` 覆盖。目录由脚本自己创建，不要手写路径，也不要放进被交接的项目仓库里。

## SAVE：存一份交接

1. 生成文档骨架，拿到文件路径：

```bash
node "<技能目录>/scripts/handoff.mjs" new --topic "<一句话主题>"
```

2. **把骨架里的每一节填成真实内容**，再写回同一文件。只引用已有的规格、计划、ADR、issue、commit、diff 的路径或 URL，不复制它们的内容。

3. 写完后跑一次脱敏自检：

```bash
node "<技能目录>/scripts/handoff.mjs" check
```

有命中就改成 `<redacted:...>` 占位符，再跑一次直到输出 `clean`。**不许带着命中收尾。**

4. 收尾时告诉用户文档绝对路径，以及一句可直接粘给新会话的话，例如：`读 <路径>，继续上面的任务`。

## RESUME：认领最近一份

```bash
node "<技能目录>/scripts/handoff.mjs" latest --cwd "<当前项目目录>"
```

脚本先在当前项目里找最近一份，找不到再退回全局最近一份，并输出用了哪个作用域（`project` / `global`）。**读取命中的文件后先向用户报出用的是哪一份，再继续干活**；如果用户说的项目对不上，停下来确认，不要硬接。

需要浏览历史时用 `node "<技能目录>/scripts/handoff.mjs" list`。

## 交接文档结构

| 章节 | 写什么 |
|---|---|
| 任务目标 | 这次到底要达成什么 |
| 当前状态 | 现在停在哪一步 |
| 关键决策与理由 | 做过的选择，以及为什么 |
| 已完成工作 | 已经落地、可验证的部分 |
| 剩余任务 / 下一步 | 接手后第一个动作是什么 |
| 已知坑 | 踩过的雷、别重复的弯路 |
| 相关文件与链接 | 路径或 URL，不复制正文 |
| 建议技能 | 下一个会话该调用哪些技能 |

模板见 [references/handoff-template.md](references/handoff-template.md)。

## 脱敏

写文档前把 API key、token、密码、Cookie、私钥、身份证号、手机号等替换成占位符，例如 `<redacted:api-key>`、`<redacted:phone>`。宁可少写，不要把凭据写进交接文件。交接文档面向本机，但用户可能共享屏幕或转发，一律按不可信处理。

## 纪律

- 只总结现状，不替接手会话做新决策。
- 不重复已有产物内容，只给路径/URL。
- 没验证过的事写「未验证」，不要写成已完成。
- 一次交接只覆盖一件事；多件独立的事分开存。

## 跨宿主调用

- 外部 Agent / 星算助手 / 万象星台：用已有命令执行工具运行上面的 Node CLI，用技能实际目录定位脚本，不依赖开发机绝对路径。
- 宿主没有 Node.js 或命令执行能力时，明确说明运行条件不足，不擅自安装运行时，也不声称已经完成交接。
